Decision Trees - Written by Giulia Nóbrega da Costa

This Notebook implements decision trees as a classification algorithm. It interprets decisions about the data as travelling through an efficient graph in order to optimize decision-making.

The dataset used is the Breast Cancer Wisconsin dataset from sklearn.datasets and we seek to classify a breast tumor as malignant/ benign based on its radius and texture.

The packages necessary for running this code are:
- numpy
- matplotlib
- sklearn
- collections
