Logistic Regression - Written by Giulia Nóbrega da Costa

This Notebook implements Logistic Regression, a linear model used for binary classification by estimating probabilities with the logistic (sigmoid) function.

The dataset used is the Breast Cancer Wisconsin dataset from sklearn.datasets and we seek to classify a breast tumor as malignant/ benign based on its features.

The packages necessary for running this code are:
- numpy
- matplotlib
- sklearn
- collections
