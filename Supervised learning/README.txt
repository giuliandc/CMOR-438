This folder contains all the notebooks on supervised learning, that is, the model learns from a labeled dataset where each input comes with a specific output.

Although there is not an explicit order in which to read the notebooks, since they are independent and each covers an algorithm, I would recommend the following if you are just getting started:

1) The Perceptron
2) Linear Regression
3) Logistic Regression
4) Neural Networks
5) K Nearest Neighbors
6) Decision Trees
7) Random Forests
8) Boosting

More about each method can be seen in their respective folders.
