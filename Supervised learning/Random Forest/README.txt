Random Forest- Written by Giulia Nóbrega da Costa

This Notebook implements a random forest classifier, an ensemble of decision trees that make a single decision based on majority rule.

The dataset used is the Breast Cancer Wisconsin dataset from sklearn.datasets and we seek to classify a breast tumor as malignant/ benign based on its radius and texture.

The packages necessary for running this code are:
- numpy
- matplotlib
- sklearn
- collections
