K-Means Clustering - Written by Giulia Nóbrega da Costa

This Notebook implements K-Means Clustering, an algorithm that finds centroids in the data and clusters them based on such.

The dataset used is the Breast Cancer Wisconsin dataset from sklearn.datasets and we seek to classify a breast tumor as malignant/ benign based on its features.

The packages necessary for running this code are:
- numpy
- matplotlib
- sklearn
- collections
