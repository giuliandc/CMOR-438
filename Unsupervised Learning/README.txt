This folder contains all the notebooks on unsupervised learning, that is, the model finds patterns in unlabeled data without human guidance.

Although there is not an explicit order in which to read the notebooks, since they are independent and each covers an algorithm, I would recommend the following if you are just getting started:

1) K-Means Clustering
2) DBSCAN
3) Principal Component Analysis
4) Image Compression with the Singular Value Decomposition (SVD)

More about each method can be seen in their respective folders.
